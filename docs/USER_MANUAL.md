# 사용자 설명서 — 1페이지: 실행 및 결과 위치

**기본 출력 위치는 실행 파일과 같은 폴더의 `result.json`과 `scan_details.json`입니다.** 소스 실행은 `main.py`와 같은 폴더에 저장합니다. 폴더에 쓰기 권한이 필요합니다. 기존 같은 이름의 파일은 다음 검사 결과로 교체됩니다. GUI에서 저장 위치를 변경하실 수 있습니다.

Windows 11 64비트에서 배포 폴더 전체를 압축 해제하고 `PublicWebAdDetector.exe`를 실행해 주세요. `_internal` 폴더를 함께 보관해 주세요. 별도 Python 설치나 GPU는 필요하지 않습니다. CLI 출력도 지원하므로 작은 콘솔 창이 함께 표시될 수 있습니다.

1. 검사 권한이 있는 시작 URL을 입력해 주세요.
2. 최대 페이지 수와 동시 작업 수를 지정해 주세요. 기본값은 200페이지, 3개 작업입니다. 모든 페이지를 보장하는 설정이 아니므로 대상 크기에 맞게 변경해 주세요.
3. `topic`은 공식 공모전 스키마를 확인한 뒤 입력해 주세요. 현재 기본 `TOPIC`은 SRS 예시 값입니다.
4. 검사 시작을 누르면 방문 페이지·후보·확정 결과·경과 시간이 표시됩니다.
5. 중지를 누르면 진행 중인 작업을 정리하고 현재까지 확인한 결과를 저장합니다. 저장이 끝날 때까지 창을 유지해 주세요.
6. 완료 후 기법 필터와 표 정렬을 사용하실 수 있습니다. 행을 선택하면 인접 문맥, 계산 CSS, 사전 일치, 판별 점수를 확인하실 수 있습니다. URL·선택자 복사와 다른 경로 내보내기를 지원합니다.

## 결과 해석

`result.json`은 `meta`, `findings`를 가진 UTF-8 무 BOM 파일입니다. 원문과 페이지 URL, 기법마다 분리된 항목을 저장합니다. `HOMOGLYPH`, `JAMO`, `TRANSPARENT`, `OFFSCREEN`만 포함합니다. `findings: []`는 확인된 필수 기법 결과가 없다는 뜻입니다. 사이트 전체가 정상이라는 보증은 아닙니다.

`scan_details.json`에는 상태(`completed`, `stopped`, `timeout`, `failed`), 방문 URL, 오류·제외, 문맥과 스타일이 있습니다. 결과가 비어 있더라도 오류와 방문 페이지 수를 반드시 함께 확인해 주세요. 필수 제출 스키마와 별도 파일입니다.

중첩 iframe은 `iframe[src="절대 URL"] >>> 요소 선택자` 형식입니다. HTML의 상대 `src` 속성과 출력의 절대 URL이 다를 수 있으므로 위치 재현에는 `LocationResolver.resolve(page, location)`을 사용합니다. 이 함수는 브라우저가 해석한 `iframe.src`를 비교하고 각 단계에서 고유성을 검증합니다. `>>>` 자체는 표준 CSS 연산자가 아닙니다.

## 명령행

```powershell
.\PublicWebAdDetector.exe --url https://example.go.kr --output .\result.json --config .\config.example.json
```

설정 파일의 `timeout_seconds`는 최대 1800초, 기본 1740초입니다. 브라우저 시작·정리 시간을 고려한 기본값입니다. `settle_ms`를 늘리면 늦게 삽입되는 DOM을 더 기다리지만 검사가 느려집니다. `keywords` 문자열 배열을 설정 파일에 추가하면 기본 사전을 대체합니다.

인증·CAPTCHA·차단 페이지는 우회하지 않습니다. 시작 URL과 동일한 스킴·호스트·포트의 링크만 따라갑니다. 내장 iframe은 외부 출처를 포함해 읽을 수 있는 범위에서 검사합니다. 이미지·동영상·웹폰트 로딩은 차단합니다.

예상하지 못한 종료가 발생하면 이전의 정상 JSON을 보존하도록 결과를 임시 파일에 기록한 후 교체합니다. 강제 프로세스 종료·전원 손실 시 현재 검사의 부분 결과 저장은 보장하지 않습니다.
